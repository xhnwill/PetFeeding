# MyPat v0.4.0

构建日期2026-11-05，ESP32-C3、4MB Flash。三只宠物新增睡觉、吃饭、玩耍各4帧动画，网页与设备共同使用96×96资源；应用0x192e80字节，应用槽剩余19%。

- mypat-v0.4.0-full.bin：首次串口刷入0x0，包含bootloader、分区表、OTA元数据与应用网页；会覆盖对应范围旧数据。
- mypat-v0.4.0-app.bin：应用OTA镜像，保留当前宠物升级使用。
- SHA256SUMS.txt：二进制完整性校验。

[动作与验证说明](../../docs/pet-actions-v0.4.0.md)。宠物数据布局未修改，旧版发布包保留回退用途；本版未烧录实物验证。
