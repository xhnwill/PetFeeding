美术与应用版本v0.3.0，日期2026-11-05。完成三只原创像素小怪兽的正面幼体立绘，并接入网页和固件。

## 交付与查看

- [角色预览页](../web/pets.html)：三只宠物的放大及96像素原尺寸展示，不会替换已养宠物。
- [原始立绘目录](../assets/pets/source/README.md)：三张透明PNG，由内置image_gen生成，原稿完整保留。
- [完整生成提示词](../assets/pets/prompts.json)：固定角色识别特征，便于后续继续动作与成长原画。
- [运行资源目录](../web/assets/pets/README.md)：96×96 PNG与角色清单。
- firmware/main/pet_art.h：对应的设备索引色像素和RGB565调色板。

在根目录启动python -m http.server 8765 --bind 127.0.0.1 --directory web，打开http://localhost:8765/pets.html。设备联网后也可访问http://设备IP/pets.html；网页主页顶部有角色预览入口。

## 显示策略

三只角色轮廓有区别，避免只靠换色区分。原稿统一转换到96×96，31个可见色加透明索引0；网页PNG与设备调色板逐像素对照。设备无需在RAM解码PNG，直接从Flash读索引像素，在20行显示缓冲中绘制；三只基础精灵数据和调色板合计27,840字节。

原有存档的species、ID和遗传信息保持不变。三种物种使用本版标准体色，原有随机色在界面以小圆徽标保留；这是视觉表现调整。已有v0.2.0网页演示存档继续可读，固件pet_t结构和schema均未改变。

本次是正面幼体基础形象；睡眠以静止和Z提示表达，成长以尺寸变化表达。独立睡姿、进食动作、受惊表情及进化分支原画均不属于本次素材交付。

## 生成和验证

运行python tools/build_pet_assets.py可重建网页PNG、清单和设备头文件。依赖Python Pillow；转换器只进行运行格式与尺寸转换，不覆盖透明原稿。

python tests/pet_art_test.py核对三只轮廓不同、透明阈值、色数上限、索引范围，以及网页颜色与设备RGB565逐像素一致。Node网页养成规则5组测试通过；ESP-IDF 5.5.4构建与合并镜像通过，应用0x142370字节，应用槽剩余约35%。

三张原稿和三张96像素资源已逐张查看。当前本机HTTP预览在浏览器中超时，角色预览页及主网页的实际浏览器布局未完成验证；不能将构建成功当作实机显示验收。尚未烧录或在240×280实物屏上验收。
