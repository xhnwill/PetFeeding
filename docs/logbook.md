# MyPat 项目日志

## 2026-10-29 可行性设计 v0.1.0

### 需求与范围

为7岁儿童设计ESP32-C3随身屏幕宠物机，提供方向键操作、首次随机宠物、吃饭玩耍、便便清洁、睡眠、真实时间逐月成长、双机互动、BLE配网与Wi-Fi联网。当前仅交付设计文档，不开发固件。

### 设计决定及理由

- 离线规则驱动养成：保证出门及网络失效时仍可使用，降低服务器依赖。
- 建议每日16小时有效睡眠达到成长上限，最快约30天一个阶段：兼顾“多睡长得快”和“现实逐月成长”。
- 区分游戏睡眠与芯片深睡：既保留睡姿查看，也能关闭背光与无线节电。
- 建议外部RTC备用供电：芯片RTC不能独立解决完全断电后的真实时间恢复。
- 朋友功能采用双方主动BLE发现、双端确认、有限会话：匹配低功耗与儿童使用场景。
- 首版非稀缺纪念礼物：避免为家庭玩法引入复杂的跨设备资产交换。
- 屏幕与Flash暂按240×240、8 MB规划：采用分块缓冲，先验证无线与显示的内存峰值。
- 不设置死亡、离家、强制签到；缺席后可继续陪伴。上述体验规则属于评审建议。
- 首版先用配套手机工具验证家长配网，自定义小程序或App单独估算。
- 使用正常提交继承PetFeeding已有历史。用户明确授权替换旧内容，远程现行树仅有旧实体喂食器README，现已替换。
