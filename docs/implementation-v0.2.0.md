# MyPat v0.2.0 实现与联调

版本与构建日期：v0.2.0，2026-10-29（北京时间）。适配旧工程 E:/MIAN/RCQB_ESP32C3，旧目录仅用于读取硬件依据，未改动。

## 当前实现

固件包含随机身份、三类可组合形象、中文界面、吃饭、摸摸、清理便便、睡眠、方向键接星星小游戏、五阶段真实时间成长、双份NVS快照、深睡恢复、BLE家长控制与配网、双机发现和配对互访、每日纪念礼物、最近朋友合照形象、Wi-Fi校时、设备内置网页与HTTPS应用OTA回滚。网页提供本地演示宠物、三轮找星星游戏、真实BLE和局域网控制、Wi-Fi配置、时间同步与HTTPS升级入口。

当前为可编译的原型版本，不表示实物已验收。完整美术动画、喜好与进化分支、相册列表、多候选好友选择、双机同步小游戏、蜂鸣音、电池电量校准与自动低压保护尚未完成。屏幕中的朋友形象是本地重绘的最近朋友纪念，不是照片传输。当前不应视作已满足设计稿全部P3体验。

## 构建与烧录

在仓库根目录执行：

```powershell
pwsh -NoProfile -File tools/build.ps1
```

脚本默认采用本机 D:/Espressif 下的ESP-IDF 5.5.4、RISC-V工具链和Python环境，可通过IdfPath与ToolsPath参数修改安装位置。源码、字体子集和网页直接内嵌，不需Node依赖安装。VS Code打开firmware目录并选择ESP-IDF扩展的esp32c3目标即可。

构建输出位于firmware/build，完整合并镜像为mypat-v0.2.0-full.bin。发布副本见releases/v0.2.0。先连接串口并确认端口，首次烧录示例：

```text
python -m esptool --chip esp32c3 -p COM3 -b 460800 write_flash 0x0 releases/v0.2.0/mypat-v0.2.0-full.bin
```

COM3是示例，必须替换为实际端口；需在已激活ESP-IDF的终端执行。完整镜像包含跨分区填充，首次刷入会覆盖旧程序及该地址范围中的旧数据；后续保留宠物升级请使用HTTPS应用OTA，不能反复写完整镜像。OTA使用mypat-v0.2.0-app.bin；错误地把完整镜像填入OTA地址将失败。

## 初次使用

1. 开机获得随机宠物。左右/上下切换吃饭、玩耍、清洁、睡觉、朋友、摸摸，OK执行。玩耍时左右移动篮筐到提示的星星列，30秒结算，BACK退出。
2. MENU打开家长模式，屏幕下方显示16位局域网访问口令；联网后上一行显示IP。
3. 电脑启动网页：python -m http.server 8765 --bind 127.0.0.1 --directory web，然后打开http://localhost:8765。页面初始为体验模式。
4. 通过支持Web Bluetooth的浏览器连接MyPat。核对系统与设备配对数字，机器按OK接受、BACK拒绝；数字显示时普通照顾操作暂停。
5. 家长设置中先校时，再输入2.4GHz Wi-Fi。密码以加密BLE消息发送，不保存到浏览器。设备获得IP后，可在同一局域网浏览器访问设备IP并输入屏幕口令。
6. 两台机器都进入朋友功能，找到后按OK。两端均可按OK，由地址排序选择唯一发起端。匹配配对数字后完成互访；每日最多一个纪念礼物，重复不会持续刷奖励。按BACK关闭发现。
7. 1分钟闲置关背光，5分钟进入宠物睡眠，5分30秒后在非BLE窗口状态关闭无线并深睡；GPIO2键唤醒。网页读取状态本身不延长唤醒时间，照顾操作会延长。
8. 没有外部RTC。已校时的深睡按RTC计算，未校时的深睡用保留区记录时长；完全断电后先保留宠物状态，网页或网络校时后补算。首次出生时间未知时，首次校时只平移已有时间轴，不凭空奖励数十年成长。

网络配置会保存到设备NVS，重启后尝试连接，连续失败最多重试4次。局域网网页在设备深睡时不可访问。独立ADC校准、电池截止阈值和整机电流尚需后续实物验证，当前续航不能套用设计估算。

## BLE与HTTP接口

服务UUID：4d500000-633a-4640-91f2-73d12144a010。状态特征0001、指令特征0002、朋友摘要特征0003，其余UUID部分一致。特征要求加密与认证，启用LE Secure Connections Only，家长广播3分钟，朋友广播60秒，单连接。原型使用自定义GATT协议，不兼容乐鑫官方配网App；网页是本版配套工具。

指令是UTF-8 JSON，以换行结尾。网页按18字节分块写入，累计最多511字节；设备将完整消息入队，由主任务执行。示例：

```json
{"action":"time","request":"abcdef01-2345","epoch":1793289600}
```

action可取feed、play、pet、clean、sleep、wake、time、wifi、friends、ota。wifi附ssid与password，ota附HTTPS应用url。request仅允许小写字母、数字、连字符，最长39字符。轮询状态中的ack和error确定执行结果；GATT写入成功或HTTP queued仅表示入队。最近一次request重复会直接复用结果；客户端不应在结果未知时用新request自动重试。

状态包含version、build、id、species、color、stage、days、growth、需求值、gifts、sleeping、clockValid、ip、配对状态、ack与error等。BLE家长窗口的认证状态读取还返回局域网token，朋友模式不会返回token。

HTTP：GET /、/app.js、/style.css提供页面；GET /api/state与POST /api/command要求X-MyPat-Token。无通配CORS，局域网口令通过设备物理屏幕获取。HTTP明文只适合可信家庭局域网；Wi-Fi配置由网页限制为BLE。设备NVS凭据尚未启用加密，生产版需另行配置NVS密钥和签名发布链。不要将此原型直接暴露到公网。

HTTPS OTA验证服务器证书并采用双槽回滚；暂无镜像签名，可信URL由家长指定。初始化与存档恢复成功后确认新镜像，未完成复杂的多版本存档迁移；schema不兼容会停止恢复而非清宠。升级时不要更改当前pet_t布局而仍沿用旧schema。
